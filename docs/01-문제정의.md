# 01. 문제정의 — LidAwake

## 배경
맥북은 화면(덮개)을 닫으면 바로 잠자기 모드로 들어간다.
다운로드, 빌드, 원격 접속, 음악 재생처럼 **덮개는 닫아도 작업은 계속 돌아가야 하는 경우**에 작업이 끊긴다.

## 현재 해결 방법과 한계
| 방법 | 한계 |
|---|---|
| `sudo pmset -a disablesleep 1` / `0` | 매번 터미널을 열고 명령어를 입력한 뒤 **관리자 비밀번호까지 쳐야 함** |
| `caffeinate` | 덮개를 닫았을 때 배터리 상태의 잠자기는 막지 못함 |
| 클램쉘 모드 | 전원 어댑터, 외부 모니터, 키보드가 모두 있어야 함 |
| 서드파티 앱(Amphetamine 등) | 기능이 많아 설정이 복잡하고, 덮개 닫힘 대응은 별도 헬퍼를 설치해야 함 |

## 핵심 문제
> 덮개를 닫아도 잠들지 않게 하는 방법은 있지만 **켜고 끄는 과정이 번거롭다**(터미널 + 비밀번호).

## 목표
- 메뉴 막대 아이콘을 **한 번 클릭하면** 잠자기 방지, **한 번 더 클릭하면** 원래대로 돌아간다.
- 비밀번호는 **최초 1회만** 입력한다.
- 지금 어떤 상태인지 아이콘만 보고 바로 알 수 있다.

## 성공 기준
- 전환에 클릭 1번, 걸리는 시간 1초 이내.
- 최초 설정 이후 비밀번호를 다시 묻지 않는다.
- 아이콘이 실제 시스템 상태(`pmset -g`의 `SleepDisabled`)와 항상 같다.
