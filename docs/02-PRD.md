# 02. PRD — LidAwake

## 개요
메뉴 막대에 상주하며, 클릭 한 번으로 `pmset disablesleep` 값을 켜고 끄는 macOS 앱.

## 대상 환경
- macOS 11 (Big Sur) 이상, Apple Silicon / Intel 모두 지원
- 사용자는 관리자 계정(최초 1회 비밀번호 입력 가능)

## 기능 요구사항
| ID | 기능 | 상세 |
|---|---|---|
| F1 | 메뉴 막대 아이콘 | Dock에는 나타나지 않고 메뉴 막대에만 상주 |
| F2 | 좌클릭 전환 | 잠자기 허용 ↔ 잠자기 방지 전환 (`pmset -a disablesleep 1/0`) |
| F3 | 상태 표시 | 방지 중일 때 ☕ `cup.and.saucer.fill`, 평소에는 🌙 `moon.zzz`. 마우스를 올리면 툴팁으로 상태를 보여줌 |
| F4 | 최초 1회 권한 설정 | 첫 전환 시 macOS 관리자 비밀번호 창을 1회 띄워 권한 규칙을 설치하고, 이후에는 비밀번호 없이 동작 |
| F5 | 우클릭 메뉴 | 우클릭(또는 Control+클릭) 시 `종료` 메뉴를 보여줌 |
| F6 | 상태 동기화 | 앱 실행 시와 전환 직후 `pmset -g`를 읽어 아이콘에 반영 |
| F7 | 종료 시 복구 | 앱을 종료하면 잠자기 방지를 자동으로 해제 (정책서 §3 참고) |

## 비기능 요구사항
- 외부 라이브러리 없음. Swift 단일 파일 + `swiftc` 빌드 (Xcode 프로젝트 불필요)
- 실행 중 메모리 30MB 이하, 평소 CPU 0% (폴링 없음)

## 배포 / 디자인
| ID | 항목 | 상세 |
|---|---|---|
| D1 | 설치 파일 | `LidAwake.dmg` (앱 + Applications 바로가기). 열어서 앱을 Applications로 끌어다 놓으면 설치 끝 |
| D2 | 아키텍처 | Apple Silicon + Intel 겸용(universal) 바이너리 |
| D3 | 빌드 | GitHub Actions macOS 머신에서 빌드해 Release `latest`에 업로드 (개발 PC가 Windows이기 때문) |
| D4 | 앱 아이콘 | 밤하늘 + 달 + 거의 덮인 맥북 틈으로 새어 나오는 빛 = "덮어도 깨어 있음". 원본 `icon/make_icon.py` |
| D5 | 메뉴 막대 아이콘 | SF Symbols(☕ / 🌙) 사용. 다크/라이트 모드에 자동으로 맞춰지고 시스템 아이콘과 톤이 같음 |

## 범위 제외 (v1)
- 타이머 자동 해제, 배터리 잔량 기준 자동 해제
- 로그인 시 자동 실행 (시스템 설정 > 일반 > 로그인 항목에서 직접 추가하는 것으로 대체)
- 앱스토어 배포, 공증(notarization)

## 수용 기준
1. 처음 클릭하면 비밀번호 창이 뜨고, 입력하면 아이콘이 ☕로 바뀐다.
2. 터미널에서 `pmset -g | grep SleepDisabled`를 실행하면 `1`이 나온다.
3. 다시 클릭하면 비밀번호 없이 🌙로 바뀌고 값이 `0`이 된다.
4. ☕ 상태에서 덮개를 닫았다 열어도 실행 중이던 작업(예: `ping`)이 끊기지 않는다.
5. 우클릭 → 종료를 누르면 값이 `0`으로 돌아간다.
6. 비밀번호 창에서 취소하면 상태가 바뀌지 않고 앱도 정상적으로 계속 동작한다.
